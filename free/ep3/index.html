무료 코드 — ZekiRex™ 플랫폼 키트

유튜브 EP3 「Claude Code로 나만의 트레이딩 플랫폼 처음부터 만들기」에서 실제로 만든 코드 전체입니다. 코드는 한 줄도 사람이 쓰지 않았고, Claude Code에게 한국어로 요청해서 만들었습니다. 무료로 쓰세요.

⬇ 키트 받기 (ZIP · 24KB)   ▶ 영상 보기

들어 있는 것

  • template.html — 화면 코드: HLC 바 차트, 50/150/200일 이동평균, 거래량, SPY 대비 RS선·RS 점수, 미너비니 추세 템플릿 스크리너, 매수·매도 신호, 백테스트, 라이트/다크 테마
  • build.py — prices 폴더의 CSV를 읽어 화면 파일 하나로 만드는 프로그램 (파이썬 3, 표준 라이브러리만)
  • Start-Mac.command / Start-Windows.bat — 더블클릭 실행 파일
  • 요청문장.txt — 영상에서 Claude Code에게 한 요청 11개 (그대로 복사해서 쓰세요)
  • README_먼저읽기.txt — 쉬운 한글 사용법

가격 데이터는 직접 넣으세요

영상에서 쓴 가격 데이터는 데이터 업체 약관상 다시 나눠 드릴 수 없어 키트에서 뺐습니다. prices/종목코드.csv, 첫 줄 date,open,high,low,close,volume 형식만 맞추면 어떤 종목이든 됩니다. SPY.csv는 꼭 넣으세요(RS와 백테스트 기준). 가장 쉬운 방법은 키트 폴더에서 Claude Code를 열고 "무료로 받을 수 있는 일봉 데이터를 prices 폴더에 이 형식으로 받아줘"라고 요청하는 것입니다. 받은 곳의 이용 약관은 꼭 확인하세요.

실행

  1. prices 폴더에 CSV를 넣는다
  2. python3 build.py (또는 실행 파일 더블클릭)
  3. 생긴 zekirex.html을 브라우저로 연다

꼭 읽어 주세요

이 키트와 영상은 교육용입니다. 투자 권유나 투자 자문이 아닙니다. 백테스트는 수수료·세금·슬리피지를 빼지 않은 계산이며, 과거 결과가 미래 수익을 보장하지 않습니다. 매수·매도 규칙은 널리 알려진 교과서 규칙을 예시로 쓴 것입니다. 코드는 있는 그대로(AS IS) 제공되며, 사용에 따른 책임은 사용자에게 있습니다.
